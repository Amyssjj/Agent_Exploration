<build>
1. HyperFrames project (hyperframes.json, meta.json, package.json scripts pinned to hyperframes@0.8.77), one index.html at 1920x1080, data-fps 60, data-duration 15. Root layers in order: WebGL canvas #gl (class clip, track 0), #agents with the four icon imgs, #typeWorld (a canvas #line1 for AGENTS CHANGE., span #intel, nine .tl spans for COMPOUNDS, div #period), #lockup (#markWrap with #shock ring and the inline two-path SVG mark, #name split into per-letter spans, #cmd with prompt, text and cursor), a grain canvas (mix-blend overlay, opacity 0.085), a CSS radial vignette, and an audio element for assets/audio/score.wav on track 10. Fonts via @font-face with font-display block.
2. Everything is a pure function of time. src/reel.js listens for hf-seek and calls renderAt(t): no clocks, no CSS animations, no state carried between frames, seeded mulberry32 PRNGs only at build time. The root GSAP timeline is an empty paused anchor. Register window.__hf.buildReady so the renderer waits until fonts are loaded, glyphs are sampled and the scene is compiled.
3. src/timing.js: BPM 120, the T table of every event time, MARKERS derived from the stroke's ease, AGENTS order, the CTA string. Import it in reel.js, type.js and tools/score.mjs so picture and sound can never drift.
4. src/reel.js (three.js): build the spine once (the bezier plus Hermite segments through nine 3D flight points, resampled every 0.016 units with parallel-transport frames), extrude the core tube and four braided satellite tubes with custom shaders (lit only after the swing, unzip uniform for the burst), sphere caps for the heads. Markers, capture ring and chart fill are flat meshes on the z=0 plane. The liquid is a full-screen raymarched SDF (core plus 4 droplet spheres, smooth-min, wobble, bounded by a sphere, writes depth). Particles, dust and sparks are Points with a shared additive shader that sizes sprites by depth and adds a circle of confusion around the focus distance. Camera = five rigs (flat, swing, chase, liquid, text) blended with smootherstep windows at 2.44, 2.95, 4.1, 8.55, plus damped-ring impact kicks at 5.0 (5 px), 7.0 (16 px), 9.0 (7 px), 10.5 (3.5 px), 12.0 (2.5 px), 13.0 (8 px). Post: EffectComposer on a HalfFloat 4x MSAA target, UnrealBloom (strength 0.55 plus pulses on the hits, radius 0.5, threshold 0.9), then one lens pass (chromatic aberration 0.0016 plus pulses, barrel 0.035, flash as an exposure multiplier so blacks stay black, highlight shoulder from 0.78, sRGB encode, per-frame dither).
5. src/type.js: lay out every line once from canvas font metrics after document.fonts.load for each face. Draw AGENTS CHANGE. into the #line1 canvas and sample those same pixels for the particle targets. The text layer is a 2D camera (look-at x, y, zoom, roll) computed in reel.js and mapped onto the WebGL text plane (screenToPlane), so DOM type and 3D particles share one camera. The lockup is designed at zoom 2.7. Film grain: one seeded 1100x660 tile, offset once per 60 fps frame.
6. tools/score.mjs (Node, no dependencies): 48 kHz stereo synthesis of every voice (kick, clap, hats, ticks, bells, marimba mallets, band-limited saw bass one octave up, detuned saw pads, booms, whooshes, risers, reverse swells, crashes, shimmer), buses for drums, music, fx, post and a reverb send. Chords: Am9-type pad on A, then F, E minor, G, resolving to A major add9 at 13.0. Mix: music ducks 55% under every kick (100 ms), Freeverb-style room 0.86, tape stop of drums+music+fx+reverb at 8.995 s over 0.36 s, the post bus (everything after 9.0) with its own reverb, 28 Hz high-pass, a little air above 6.5 kHz, glue compression, peak to 0.9 and tanh soft clip, 5 ms fade-in and 50 ms fade-out, written as 24-bit assets/audio/score_raw.wav.
7. tools/finish.sh: run the score, then two-pass loudnorm (I -14, TP -1.2, LRA 11, linear) to assets/audio/score.wav; run hyperframes check (0 errors, 0 warnings); write a temporary index-mb.html that plays the film 4x slower (root and #gl durations 60, audio removed, window.__reelStretch = 4 so the seek handler divides time by 4); hyperframes render --composition index-mb.html --fps 240 --quality looks --crf 4 (14,400 captures, 16 true sub-frames per output frame).
8. Motion blur and master encode in one ffmpeg pass: zscale to linear light (gbrpf32le), tmix of 16 equal weights, keep every 16th frame, setpts to 60 fps, zscale back to sRGB limited-range yuv420p, mux the score. libx264 High 4.2, preset slow, CRF 14, BT.709 tags, AAC 320 kb/s 48 kHz, faststart, -t 15. Output renders/digital-me-launch.mp4: 1920x1080, 60 fps, 900 frames, exactly 15.000 s, about 25 Mb/s, -14 LUFS. Delete the roughly 2 GB sub-frame capture afterwards.
9. tools/sheet.sh builds labelled contact sheets from any render. Check a 60 fps draft (no blur, about 10 s to render) at every eighth note before the final pass: one focal point per frame, all four icons inside frame during the orbit, no small text, the dot always findable.

<gotchas>
When forking an engine, grep for every old element id. Here the particle-target sampler still read the old canvas id and the whole build threw, so every frame rendered black.
The site's icon SVGs declare width and height of 1em, so as img elements they rasterize tiny and blurry. Rewrite them to 256 and scale down with transforms; never tint or redraw them. Icons are DOM overlays, so fade them out before the droplets merge or they float over the core.
Sample particle targets from the very canvas that displays the line, after fonts load, or the particles land a few pixels off the type and the snap jumps.
Additive points near the lens fuse into a flat white frame at the burst; scale sprite size with camera distance. A flash must multiply exposure, not add light, or the whole frame lifts to grey.
Keep the grain pattern constant within each 60 fps frame, or the 16-sample accumulation averages it away.
HyperFrames' CLI does not expose its native motion blur, hence the 4x stretch plus 240 fps capture. HyperFrames later stamps data-hf-id attributes into index.html (it did 33 s after this render), which breaks literal string replacements like '<canvas id="gl"' and '<audio id="score"' in the stretch step; match with regexes that tolerate extra attributes, and assert the audio tag is gone.
zscale refuses the linear conversion unless matrix, primaries and range are given both in and out, and after tmix the frames lose their tags, so declare transferin=linear explicitly on the way back.
zsh does not word-split variables: wrap the CLI in a function, not a string alias.
hyperframes check flags the deliberately overlapping COMPOUNDS letters and the letters falling off canvas: mark them with data-layout-allow-overlap and data-layout-allow-overflow, and park (hide) each letter 0.75 s after it starts falling.
You cannot listen to the score: verify it with a spectrogram and per-band balance against the event grid. Long decay tails can look like low-end rumble before the first hit; profile each bus before "fixing" it.
